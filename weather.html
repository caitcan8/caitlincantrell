Weather Widget

Github repository: Weather Widget

Description

In this project, I designed a weather app widget using Javascript, CSS, and Electron. It fetches accurate weather data from WeatherApi and displays weather data based on a city of the users choosing. It is designed to look like a standalone widget with a clean user interface.

Key Features

  • Frontend: CSS, HTML, and JavaScript
  • Backend: WeatherAPI
  • City searching: compatible with any city worldwide
  • Displays temperature (current, high and low), conditions, UV index, and chance of rain
  • Hand drawn custom weather condition images and clean UI
  • Error handling for invalid cities
  • .env variables to secure API keys

Usage

  • Clone Repository
  • Set up your WeatherApi key.
  • Create a file named .env in the root folder. and add your API key (WEATHER_API_KEY=your_api_key_here).
  • Run the widget: npm start
